# 变更说明（2026-09-18）

版本：v1.2.7 → v1.2.8，文件：`cn-map-card.js`

## 背景 / 原因

新版 HomeAssistant（2024.4 起，延伸到 2025.x / 2026.x）前端做了三类破坏性变更，导致本卡片加载即报错：

1. **Lit 3**：`LitElement.prototype.html / .css` 被删除，且 custom card 模块求值时
   `customElements.get("ha-panel-lovelace")` 可能尚未注册 —— 旧代码
   `Object.getPrototypeOf(customElements.get("ha-panel-lovelace"))` 会在模块顶层直接抛
   `TypeError`，表现为 "Custom element doesn't exist: gaode-map-card"。
2. **旧组件被移除**：`paper-input`、`mwc-formfield`、`mwc-radio`、`ha-icon-button`、
   `ha-entity-marker`、`hui-*` 内置卡片元素等逐步从 HA 前端删除，编辑器空白、标记点不显示。
3. **themes 结构重构（2024.4）**：主题变量嵌套进 `themes[name].variables`，
   `default_theme` 可能为 `null` —— 旧代码在 `dark_mode: auto` 下取
   `hass.themes.themes[newTheme]["primary-background-color"]` 抛错，且每次状态更新都中断。

## 本次改了什么

| 位置 | 改动 | 原因 |
| --- | --- | --- |
| 模块头部 | 删除 `preloadCard`（`window.loadCardHelpers`）与 `ha-panel-lovelace` 取 Lit 原型的一整套 hack | 消除模块顶层崩溃；卡片主体本就是普通 `HTMLElement`，只有旧编辑器需要 Lit |
| `setConfig`（卡片） | 删除 `preloadCard('map')`、`customElements.get("hui-map-card")` | `hui-*` 元素在新版不保证注册 |
| 构造函数 | 删除 `this.root.removeChild(root.lastChild)`（裸 `root` 引用必抛的真 bug） | 新 ShadowRoot 无子节点，该行多余且危险 |
| `set hass` | 主题判断改用新增的 `_themeVars()` / `_isDarkTheme()`，同时兼容新（`variables` 嵌套）旧（平铺）结构，背景色取不到时回退白色 | 适配 2024.4 themes 重构 |
| `set hass` / `_loadMap` | `entities` 缺失、实体状态不存在、按钮未创建时增加空值保护；实体按钮文案做 HTML 转义 | 防止配置不完整时整卡崩溃 |
| 卡片标记点 | `ha-entity-marker` → 自带 `.entity-marker`（首字母彩色圆点 / 头像图片）；zone 的 `ha-icon` → 内联 SVG 房屋图标 | 这些元素在新版 HA 已删除或不再保证存在 |
| 复位按钮 | `ha-icon-button` → 原生 `<button>` + 内联 SVG | 同上 |
| 编辑器 `GaodeMapCardEditor` | 整体重写为不依赖 Lit 的纯 DOM 自定义元素；`paper-input`/`ha-switch`/`mwc-radio`/`hui-entity-editor` 全部换成原生 input/select/radio；保留 `config-changed` 事件协议与全部配置项（title、aspect_ratio、default_zoom、traffic、hours_to_show、dark_mode、entities、key） | 一次性摆脱所有被删除的组件依赖，兼容新旧 HA |
| `window.customCards` | 注册前去重 | 防止 HA 新版多次加载资源时重复注册 |
| 样式 | `--paper-item-icon-active-color` 增加回退值；新增 `.entity-marker`/`.zone-marker`/`#fitbutton` 样式 | 旧 CSS 选择器指向的元素已不存在 |

## 未改动 / 待验证

- 未改 `dist/` 内旧的 v1.2.4 副本与 `w3color.js`。HACS 若配置指向根目录 `cn-map-card.js` 则不受影响。
- 高德 loader 仍以 `import 'https://webapi.amap.com/loader.js'` 方式加载，未改动。
- 代码已通过 `node --check` 语法校验；**尚未在真实的新版 HA 实例里跑通 UI**，
  请在目标版本（2026.x）验证：卡片渲染、跟随主题深浅切换、标记点头像/首字母、
  历史路径、编辑器各配置项保存。
